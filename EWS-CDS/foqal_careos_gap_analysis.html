Prioritized Gap List — All 12 Items
# Priority Screen Gap Description Clinical / UX Impact
1 🔴 Critical N2 Default escalation radio is Nurse → Doctor. Wireframe mandates Nurse → Head Nurse first. Attending is only reached via Head Nurse decision. Violates the intended clinical escalation hierarchy. Head Nurse triage is a key safety step.
2 🔴 Critical N5 "Escalate to Attending" and "Mark False Alarm" buttons are absent from the N5 queue rows. Head Nurse must navigate to N1b to perform either action. High workflow friction — charge nurse cannot act from the queue. Delays response time.
3 🟡 High N1 / N1b DCM Phenotype A/B/C classification is absent from the EWS Reason cell and the ML Insights tab. Core clinical DSS feature — Phenotype C (Cardiogenic Shock) triggers a different response protocol than Phenotype A (Decompensated HF).
4 🟡 High N3 Post-escalation screen shows only the escalated patient. Wireframe shows all ward patients so the nurse retains situational awareness. Nurse loses full ward context immediately after raising an escalation.
5 🟡 High N5 "HN Decision" column absent from the escalation table. There is no way to see what the Head Nurse has decided for each escalation from the queue view. No visibility on triage status — attending cannot see if a patient has been assessed by HN or is still pending.
6 🟡 High N1b Data source tags (monitor), (manual), (lab/HIS) absent from main vitals table rows. Only present in the DCM card below. Clinical staff cannot quickly verify data provenance — critical when assessing automated vs. manually recorded vitals.
7 🟠 Medium N4 Status Log timeline lacks Head Nurse intermediary steps ("HN Acknowledged", "HN Escalated to Attending"). Timeline jumps from nurse notification to doctor acknowledgement. Incomplete audit trail for NABH compliance — head nurse triage step should be logged.
8 🟠 Medium N1b ML Insights tab missing DCM EWD scope table (detection logic, phenotype descriptions, what it does NOT cover, false alarm feedback loop). Without this, clinical staff do not know the model's scope or limitations.
9 🟠 Medium N_transfer 4 stat tiles (NEWS2, stable window, current ward, approval status) missing from the submitted recommendation state. Nurse has no visual summary of the transfer eligibility after submission.
10 🟢 Low N4b "Escalate to CMO" button absent from post-resolution footer. CMO escalation path not wired — minor since critical events would use Code Blue directly.
11 🟢 Low N1 Column labelled "EWS Reason" — wireframe uses "EWD Reason" (Early Warning Detection, not Score). Naming inconsistency with wireframe spec — "EWD" is the product's preferred terminology.
12 🟢 Low N5b Missing note "inherits from SA2 global" in threshold table header. Minor informational gap — users may not know these are overrides of global thresholds.
