Master Data Schema — 9 Tables

New shared schema. Neither the EWS app nor the Discharge AI app owns this — both connect to it as a read layer. The central table is admissions whose admission_id UUID is the universal key flowing into all downstream tables. HOSPITALS acts as the top-level tenant anchor for multi-hospital scalability.

Discharge Summary AI Schema (Key Integration Changes)

The Gemini pipeline, MedCPT embeddings, Qdrant RAG, BM25, and all 18 ap_* MIMIC-IV clinical tables are unchanged. The changes shown here integrate Ashmit's system into the shared identity layer. ADMISSIONS and STAFF are reference entities from hospital_core.

Doctor sign-off chain: At discharge, app_summaries.signed_by is resolved by querying doctor_patient_assignments WHERE assignment_type='PRIMARY' AND unassigned_at IS NULL for this admission — guaranteeing the correct treating consultant signs the NABH discharge summary.

Key Integration Queries

Critical SQL queries that tie the two systems together at discharge and escalation sign-off.

Get Current Treating Consultant for an Admission
SELECT s.staff_id, s.full_name, s.role
FROM hospital_core.doctor_patient_assignments dpa
JOIN hospital_core.staff s ON s.staff_id = dpa.doctor_id
WHERE dpa.admission_id = :admission_id
  AND dpa.assignment_type = 'PRIMARY'
  AND dpa.unassigned_at IS NULL;

STEP_DOWN_ELIGIBLE Auto-Trigger (runs every hour)
SELECT admission_id
FROM ews.vitals_timeseries
WHERE chart_hour >= now() - interval '6 hours'
GROUP BY admission_id
HAVING MAX(news2_score) <= 2
  AND admission_id NOT IN (
    SELECT admission_id FROM ews.escalations
    WHERE initiated_at >= now() - interval '24 hours'
  );
Close Admission on Discharge
UPDATE hospital_core.admissions
   SET status = 'discharged', discharged_at = now()
 WHERE admission_id = :admission_id;

UPDATE hospital_core.beds
   SET status = 'available', current_admission_id = NULL
 WHERE current_admission_id = :admission_id;

UPDATE hospital_core.doctor_patient_assignments
   SET unassigned_at = now()
 WHERE admission_id = :admission_id
   AND unassigned_at IS NULL;
