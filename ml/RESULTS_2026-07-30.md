## 1. The 2×2 — the central result

Same split, same person-period masking, same isotonic calibration, same survival
reconstruction. Only the target and the feature set vary.

| | 55 NEWS2-derived features | multi-window feature set | Δ AUC |
|---|---|---|---|
| **NEWS2 ≥ 7 sustained 2h** | AUC 0.8120 | AUC 0.8141 (370 feats) | **+0.0021** |
| **escalation of care** | AUC 0.7249 | AUC 0.7974 (80 feats) | **+0.0725** |

**The identical feature set is worth 35× more on one target than the other.**

### Why

NEWS2 is a deterministic function of seven vital signs. Anion gap, MAP, lactate,
bicarbonate and infusion titration **cannot** improve a prediction of NEWS2, because
they do not enter its formula — they can only act through their eventual effect on
those same seven vitals, which the vitals features already capture.

Against escalation, where metabolic acidosis and hypoperfusion are *direct causal*
mechanisms, the same features are worth +0.073 AUC.

**This retrospectively explains the null labs result** from the earlier iteration:
labs were tested against a NEWS2 target, where they were arithmetically incapable of
helping. Not bad luck — a design error.

### Full detail

| | A (NEWS2, 55) | B (NEWS2, 370 mw) | C (esc, 55) | D (esc, 80 mw) |
|---|---|---|---|---|
| base rate @12h | 0.1204 | 0.1204 | 0.0465 | 0.0465 |
| C-index | **0.7860** | 0.7847 | 0.7109 | 0.7708 |
| C-index 95% CI | [0.767,0.806] | [0.764,0.805] | [0.679,0.746] | [0.736,0.806] |
| train/test gap | **0.0151** | 0.0443 | 0.0505 | 0.0562 |
| AUC @12h | 0.8120 | 0.8141 | 0.7249 | 0.7974 |
| AUPRC @12h | 0.3982 | 0.4029 | 0.1270 | 0.2135 |
| episode-PPV @12h | 0.3311 | 0.3403 | 0.1142 | 0.1338 |
| episode-LIFT @12h | 2.750 | 2.827 | 2.456 | **2.878** |
| patient recall | **0.9673** | 0.9548 | 0.9356 | 0.9442 |
| alarms/day/100 pt | 127 | 120 | 120 | 104 |

**Decisions taken:**
- **Cell B rejected.** +0.002 AUC, recall −1.25pp, 6.7× the features, overfit gap
  tripled. Do not use multi-window features on the NEWS2 target.
- **Cell D adopted** over C. +0.073 AUC. Pruned 371 → 80 features (0.7780 → 0.7708,
  indistinguishable within overlapping CIs) because the simpler of two equivalent
  models is the defensible one, and it moves toward the JAMIA "<39 variables" finding.
- **Overfitting is sample-size-bound, not feature-bound.** Pruning 4.4× closed only 18%
  of the excess gap (0.0686 → 0.0562) with 1,475 event-stays. Further pruning discards
  signal; the gap will not go below ~0.05 on this cohort.

## 2. The escalation target

### Definition

```
COHORT RESTRICTION (the DETERIO rule verbatim: exclude deterioration before hour 2)
  all CCU stays                                    10,775
    excluded: escalation or death within first 2h   2,965
    excluded: CCU stay shorter than 2h                 53
  ELIGIBLE COHORT                                   7,757

EVENT = first of, within the eligible cohort:
  pressor 696 · death-alone 424 · vent 350 · rrt 164 · rescue 127
  severe_shock 116 · acute_event 97 · mcs 60
  -> 2,034 events / 7,757 stays = 26.2% prevalence
```

Field prevalence for comparison (JAMIA 2024, 14 deployed systems): **ICU 11.3–32.8%**.
NEWS2 ≥ 7 sits at **50.3%**, above the entire published range.

**Correction to an earlier figure in this project:** 17.7% prevalence was reported
earlier. It was computed as `min(first_escalation, death) ≥ 2h`, which wrongly drops any
patient whose *first* escalation was early even when they had a later qualifying event.
The correct figure is **25.5%** (26.2% with the shock safety net).

### Why NEWS2 ≥ 7 was the wrong target for a CCU

Its protocol meaning is *"emergency response, continuous monitoring, escalate to
ICU-level care."* These patients already receive all of it. **The alert's intended
action is already standing, so the alert is actionless** — which is why it occurs in
half the unit and why 127 alarms/day/100 patients is unavoidable.

14 of 14 systems in the JAMIA review predict ICU transfer, escalation, arrest or death.
None predicts a vital-sign score threshold.

### Data that had to be re-extracted first

`00_extract_cohort.py` filtered `chartevents` to the seven NEWS2 parameters and
`labevents` to ten labs, so the entire feature substrate had been selected to *compute
NEWS2*. **A filtered extract makes its own feature set look complete** — the omissions
were invisible in the parquet files and required `d_items` queries to find.

| Added | Coverage on this cohort |
|---|---|
| `220181` **NIBP mean (MAP)** | **98.3%, 56 readings/stay** — previously approximated as (SBP+2·DBP)/3 |
| flowsheet labs incl. **HCO3, anion gap** | 95.8–96.9%, ~6/stay |
| GCS components (motor/eye/verbal) | 99.1% (only the total was held) |
| nurse-concern signals (alarm limits, params checked) | 95.6–99.0% |
| Braden frailty components | 98.2% |
| labevents: lactate, bilirubin, pH, pO₂, pCO₂, base excess, albumin | 56.8–72.1% |
| escalation therapies: **IABP, Impella, ECMO**, cardiac arrest, defibrillation, standalone intubation, pericardiocentesis, temporary pacing | +312 stays previously invisible |
| infusion titration (allow-listed) | 80.5% of stays |

**Leakage guards, asserted in code not merely intended:**
- ventilator settings (PEEP, tidal volume) excluded — they exist only *after* intubation,
  which is an event; their ~27% coverage *is* the ventilated fraction
- vasopressors excluded from infusion features — they **are** the target
- propofol/fentanyl/midazolam excluded — induction agents given *at* intubation
- packed red blood cells excluded — arguably an escalation itself

| family | share | family | share |
|---|---|---|---|
| renal (creat/BUN/eGFR) | 8.5% | infusions | 4.4% |
| SBP | 7.7% | SpO₂ | 4.3% |

- **Anion gap holds the #1, #2, #3 and #5 individual slots.** Metabolic acidosis moves
  *before* the vitals do — the "NEWS2 = 3 but deteriorating" patient.
- **83.1% of total gain comes from newly extracted features.** `news2_mean`, the #1
  feature on the old target, falls to 12th.
- **Vitals are 32.5% of gain**, not absent. They looked absent in a top-20 list because
  gain dilutes across 19 features per vital while anion gap concentrates into 12.
  **Ranking individual features is invalid when variables have unequal feature counts.**
- **47.3% of gain from window/trend/delta features** — 2h: 8.3%, 6h: 12.0%, **12h: 13.7%**.
- Matches published ICU work, which finds labs and organ-function markers outrank
  transient hemodynamic fluctuations, and names anion gap, lactate, bicarbonate, BUN
  and pH specifically.

## 3. False-alarm levers, classified

The central methodological point: **"reducing false alarms" means three different things
and they must not be reported as one.**

| Kind | Lever | Recall cost | Effect |
|---|---|---|---|
| **Free** | hazard-profile re-ranking | none | precision 0.19 → **0.57** on the top 10% of the worklist |
| **Behaviour** | hysteresis (dual threshold) | none | alarms 99 → 67, lead 9.0 → 11.0h |
| **Frontier** | 24h horizon over 12h | none | base rate 2×, lead time up |
| **Frontier** | lower sensitivity | real | PPV up, recall and lead time down |
| **Frontier** | conformal α=0.20 | real | lift +20% for −5.6pp recall |
| **Counting** | episode gap | none — recall invariant | a reporting convention only |

### Hazard-profile re-ranking — the best result

Precision@K over 1,359 alert episodes at 24h. **Nothing suppressed; order only.**

| top K% | episodes | precision | vs all |
|---|---|---|---|
| 10% | 135 | **0.5704** | 2.95× |
| 25% | 339 | 0.4307 | 2.23× |
| 50% | 679 | 0.2842 | 1.47× |
| 100% | 1,359 | 0.1935 | 1.00× |

Descriptor decile spreads:

| descriptor | Spearman | PPV low decile | PPV high decile |
|---|---|---|---|
| `hz_cum_loghazard_12h` | +0.2435 | 0.0642 | 0.3892 |
| `hz_roughness` | +0.2153 | 0.0804 | 0.3614 |
| `hz_mean_accel` | −0.1861 | 0.3422 | 0.0784 |

**Honest attribution:** `hz_cum_loghazard_12h` = −log S(12h) is a monotone transform of
the 12h probability, so ranking by it means "prioritise 24h alerts by 12h risk" —
sensible but not a new signal. **`hz_roughness` is the genuinely novel one**: the shape
of the hazard curve across the seven independent boosters, not a transform of any single
probability. **It exists only because those boosters are independent** — a shared-trunk
model would smooth it away.

### Hysteresis

Fire at `τ_high`, release only below `τ_low` (Schmitt trigger). Unlike the episode gap,
which merges alarms *inside the metric*, this stops the second alarm being *generated*.

| horizon | episodes | ep-PPV | ep-LIFT | recall | alarms/day/100 |
|---|---|---|---|---|---|
| 6h | 2,321 → 1,754 | 0.2714 → 0.3529 | 4.171 → 5.423 | 0.9439 → 0.9502 | 128 → 97 |
| 12h | 2,069 → 1,551 | 0.3311 → 0.4101 | 2.750 → 3.406 | 0.9673 → 0.9751 | 127 → 95 |
| 24h | 1,693 → 1,307 | 0.4341 → 0.4996 | 1.908 → 2.195 | 0.9782 → 0.9782 | 129 → 100 |

**Self-criticism, required when presenting this:**
- Part of the PPV gain is merging. Decomposed at 12h: true episodes fell 7%, false fell
  34% — false alarms are *flicker*, true alarms are *sustained*, so it merges the false
  preferentially. Real separation, still partly a counting effect.
- **An earlier claim that rising lead time proved genuine earlier detection was wrong.**
  The episode gap alone raises lead time 7.0 → 9.8h, because a merged episode inherits
  the earlier start. **Lead time is not merging-independent.**
- Only **patient recall** survives as non-definitional evidence — it counts patients, not
  episodes.
- Human factors: the nurse sees **fewer but longer** alarms. Whether 95 long alarms beat
  127 short ones is a clinical question, not a modelling one.

### Episode gap — a convention, with the curve

| gap | episodes | ep-PPV | **recall** | alarms/day/100 |
|---|---|---|---|---|
| 1h | 3,467 | 0.3098 | **0.9673** | 213 |
| **2h (chosen)** | 2,069 | 0.3311 | **0.9673** | 127 |
| 8h | 1,513 | 0.4111 | **0.9673** | 93 |
| 12h | 1,394 | 0.4455 | **0.9673** | 86 |

Recall is invariant at every value. 12h would report 0.4455 instead of 0.3311 for free.
**2h chosen deliberately as the conservative end.** Published precedent exists at 4h
(MEWS++), 6h (DETERIO, disclosed as a "clinical response policy") and 8h (Mayo MC-EWS).

### Why PPV is low — arithmetic, not a model defect

```
PPV = sens·base / (sens·base + FPR·(1-base))
```

| horizon | base rate | spec needed for PPV=0.30 @80% sens | actual spec |
|---|---|---|---|
| 12h | 0.0465 | 0.9090 | 0.6096 |
| 24h | 0.0948 | 0.8045 | 0.5614 |

Reaching PPV 0.30 at 80% sensitivity requires removing **77% of current false positives
while losing no true positives** — larger than any discrimination gain in this project
or the published field. **PPV at high sensitivity is a prevalence constraint.**

### Conformal YES/NO/IDK

Label-conditional (Mondrian) conformal prediction produces the three tiers natively,
with a distribution-free coverage guarantee, needing no ensemble and no retraining.

```
{1} PAGE   {0} CLEAR   {0,1} WATCH   {} out-of-distribution
```

| α | %PAGE | %WATCH | PAGE ep-PPV | PAGE lift | PAGE recall | events in WATCH |
|---|---|---|---|---|---|---|
| 0.05 | 8.2% | 67.9% | 0.2643 | 5.683 | 0.6953 | 59.4% |
| 0.10 | 15.0% | 53.9% | 0.2078 | 4.468 | 0.8197 | 42.2% |
| **0.20** | **26.2%** | **26.1%** | **0.1602** | **3.445** | **0.8884** | **20.1%** |

**Methodological fix applied:** an earlier version computed conformal quantiles on the
same split the isotonic calibrator was *fitted* on. Those probabilities are
optimistically calibrated there, so the quantiles were too tight — **breaking
exchangeability and voiding the coverage guarantee that is the entire reason to use
conformal.** Now the calibration split is halved **by patient**. Effect at α=0.10:
PPV 0.226 → 0.208, recall 0.764 → 0.820 — less confident, correctly so.

Nulls: the out-of-distribution tier is **0.0%** everywhere; asymmetric α slides along
the same frontier rather than beating it.

**Load-bearing caveat:** at α=0.10, **42% of true events land in WATCH.** Safe only if
the worklist is genuinely reviewed. That is a human-factors dependency, not a result.

## 4. Tried and rejected

| Attempt | Result |
|---|---|
| **Persistence voting (k-of-m)** | +18% PPV, −34% alarms, **but drops 58% of patients having only 1–2 pre-event observations** — a 2-of-6 rule cannot fire on someone who crashes after two readings. Median max-lead of those dropped: 1.0h vs 11.0h kept. Rejected clinically. |
| **Interval voting (OR/majority)** | Provable no-op. `P(T≤2h) ≤ … ≤ P(T≤24h)` by construction, so every k-of-7 vote equals thresholding one horizon. Agreement **1.0000**. |
| **Two-stage cascade** | Base rate rises 0.0465 → 0.0740, but **lift falls** 2.878 → 2.088 in every variant. The filter removes easy negatives, so the residual problem hardens faster than prevalence rises. NEWS2≥5 filter also discards 42% of events irrecoverably. |
| **"No alert within 2h of admission"** | −27 episodes, PPV unchanged, **−3pp recall.** Bad trade; largely redundant with the >2h cohort rule. |
| **"Re-alert only if risk rose"** | +3 episodes, PPV −0.001. Exact null — **hysteresis already subsumes it**, because the latch prevents the boundary flicker that generates re-alerts. |
| **Anchor-level uncertainty gating** | Splits an episode mid-run → PPV moved **backwards** 0.3073 → 0.2834. |
| **Hard alarm-budget cap** | Suppresses the 11th real alert to protect a metric. Clinically indefensible; dropped. |
| **Ward top-K precision@K** | Test split has a median of **1 concurrent patient per wall-clock hour** (1,360 patients over 2008–2019). Unsimulatable without a synthetic ward. |
| **`keep_high_anchors`** | +3,923 rows, **0** additional patients recovered. |
| **Hazard incoherence / leaf support as *confidence*** | Both correlate **positively** with being correct (+0.214, +0.073) — they are risk signals, so gating on them would suppress the best alerts. Incoherence retained as a *feature* instead. |
| **Architecture: 7-independent → pooled XGB → multi-head MLP → cumulative MLP** | Spread **0.0093** across all four against CIs ~0.040 wide. Parameter sharing alone: **−0.0007**. An 8-config MLP sweep spanned 0.7% of validation loss, so not a tuning failure. |
| **Cost-sensitive training, per-subgroup thresholds** | Slide along the existing frontier; the NEWS2 5–6 band has the *highest* row-PPV (0.3069), so the obvious suppression target is the wrong one. |

## 5. Errors found and corrected this session

| Error | Correction |
|---|---|
| Prevalence reported as 17.7% | **25.5%** — `min(esc, death) ≥ 2h` wrongly dropped patients with a later qualifying event |
| `GroupShuffleSplit` unstable across cohorts | v1/v2 builds agreed on only **53%** of split assignments, confounding every cross-label comparison. Replaced with deterministic `md5(subject_id\|seed)`; unit test asserts 100% agreement after dropping 30% of subjects |
| Episode merging used positional adjacency | Timestamp-based. Two alarms hours apart were merging when no anchor was charted between |
| Alert threshold fitted on test labels | Fitted on calibration; honest out-of-sample sensitivity is **81.1%**, not 80% |
| Conformal quantiles computed on the isotonic-fitting split | Halved by patient; coverage guarantee restored |
| Claimed lead time was merging-independent | **It is not** — the episode gap alone raises it 7.0 → 9.8h |
| Cell C run with mismatched features after diagnosing the mismatch | Cell D built with target-appropriate features: +0.073 AUC |
| `episode_stats` passed 0.5 where the calibrated threshold belonged | Produced a nonsense 13-episode baseline; fixed and asserted in the docstring |
| "Re-alert if risk rose" masked alert *rows* | Fragmented runs 1,801 → 3,752 episodes. Rebuilt on episode boundaries |

**Recurring pattern worth naming:** four separate bugs were the same class —
**applying a row-level operation to an object that spans multiple rows** (label
adjacency, episode merging, uncertainty gating, re-alert suppression).
